# video-to-obsidian

把视频链接变成结构化 Obsidian 笔记的一条命令流水线。支持**抖音**、**哔哩哔哩**，其他站点由 yt-dlp 兜底，合集 / 播放列表自动展开。

## 安装

不需要手动敲命令。把下面这条指令复制给你正在使用的 AI 工具（WorkBuddy / Claude Code / Codex 等已接入本技能的会话）：

```
浏览 https://github.com/grimm-yh/video-to-obsidian 这个链接，并安装到我本地
```

AI 会自动完成下载、安装、配置和校验。安装过程中 AI 会向你申请所需的权限和登录信息（见下节），全部就绪后会做一次完整校验，各项通过即提示**安装完成**。

## AI 会自动安装的工具与所需权限

**自动安装的工具**（AI 逐项执行，无需手动操作）：

| 工具 | 用途 | 说明 |
|---|---|---|
| `faster-whisper` / `numpy` | 本地语音转写 | 音频不离开本机 |
| CUDA 相关依赖 | 显卡加速 | 有 NVIDIA 显卡时装，纯 CPU 跳过 |
| 转写模型 large-v3 | 约 3.1GB | 自动下载到本地模型目录 |
| `ffmpeg` / `ffprobe` | 音视频处理 | 已存在则跳过 |
| `yt-dlp` | 其他站点兜底与合集展开 | |
| Chromium 系浏览器 | 抖音抓取用隔离实例 | 可复用本机已有的 Chrome / Edge，不强制安装 |

**会向你申请的权限与信息**：

| 项目 | 用途 | 不提供的后果 |
|---|---|---|
| B 站登录（扫码） | 720P/1080P 画质 + 读取字幕列表 | 只有 480P，且无法用平台字幕 |
| 抖音链接处理 | 启动**独立**浏览器实例抓取接口 | 与你日常浏览器完全隔离，不需要你的抖音账号 |
| DeepSeek API Key（可选） | 画面文字识别 | 不识别画面上的文字卡，其余功能不受影响 |
| 网络访问 | 调用平台接口、下载视频和模型 | 无法工作 |

## 方案流程

```text
视频链接
  │
  ├─ 抖音 ──→ 隔离浏览器实例抓接口 ─┐
  ├─ B 站 ──→ 公开 API + 平台字幕 ──┤
  └─ 其他 ──→ yt-dlp 兜底 ─────────┤
  │                                │
  ▼                                ▼
最高可用画质下载 ──→ 有平台字幕直接用，否则本地转写 ──→ 可选：识别画面文字
  │
  ▼
生成带 frontmatter 的笔记草稿（待 AI 归纳入库）
```
